# Tabler

Query CSV, Excel, Parquet, and JSON files with SQL directly in your browser. Tabler runs DuckDB in-browser, so your data never leaves your device. No signup, no upload.

## Installation

```bash
bun install
```

## Development

```bash
bun run dev
```

## Build

```bash
bun run build
```
